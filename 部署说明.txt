========================================
  Q币充值 - 免费部署 & 手机访问说明
========================================

【可以】上传到免费服务器，手机用浏览器打开链接即可。

推荐方案（按难度排序）：

----------------------------------------
方案 A：Render 免费云（推荐，有 HTTPS）
----------------------------------------
适合：长期挂着、手机随时访问
网址：https://render.com （注册免费账号）

步骤：
1. 把整个项目文件夹上传到 GitHub（新建仓库，拖入文件后 push）
   ※ config.json 里的 Cookie 敏感，建议上传前清空 cookie/xsrfToken 字段，
     或把 config.json 加入 .gitignore，部署后在网页「Cookie 配置」里填写。

2. 登录 Render → New → Web Service → 连接你的 GitHub 仓库

3. 设置：
   - Runtime: Python 3
   - Build Command: 留空或 echo ok
   - Start Command: python server.py
   - Instance Type: Free

4. 部署完成后得到地址，例如：
   https://qb-recharge-xxxx.onrender.com
   手机浏览器直接打开即可（自带 HTTPS）。

注意：
- 免费版 15 分钟没人访问会休眠，第一次打开要等约 30 秒唤醒。
- 服务器在美国，国内访问可能稍慢。
- 重启/重新部署后 Cookie 可能丢失，需在手机里重新配置 Cookie。

----------------------------------------
方案 B：内网穿透（不租服务器，电脑开着）
----------------------------------------
适合：临时用手机测、不想上传代码

1. 本机运行 启动.bat
2. 下载 cpolar 或 ngrok（国内用 cpolar 较稳）
   https://www.cpolar.com
3. 映射本地 8765 端口，得到公网 https 链接
4. 手机打开该链接

缺点：电脑要一直开着。

----------------------------------------
方案 C：Replit（在线运行，免装环境）
----------------------------------------
1. 打开 https://replit.com 注册
2. Create Repl → Import from GitHub 或上传文件
3. Run 运行 server.py，点 Webview 获取链接
4. 手机访问 Replit 提供的 URL

----------------------------------------
手机使用注意
----------------------------------------
1. 先在同一浏览器登录 www.hnlsxxkj.com（或在本站配置 Cookie）
2. 支付页若内嵌空白，点「新窗口打开」完成支付
3. 不要把带 Cookie 的链接发给陌生人（等于账号权限）

----------------------------------------
安全建议
----------------------------------------
- 仅自己或信任的人使用
- 定期在「Cookie 配置」更新 Cookie
- 勿将 config.json 发到公开群
